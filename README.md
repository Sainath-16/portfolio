## ✨ Architectural Highlights & Features

* 🎨 **Dynamic Glassmorphism UI:** Sophisticated dark-mode design featuring backdrop blur cards, ambient gradient orbs, and bespoke border-glow hover effects (`glow-cyan`, `glow-violet`, `glow-emerald`, `glow-blue`).
* ⚡ **Next-Gen Performance:** Built on top of Next.js 16 App Router and React 19 for blazing-fast static page generation (SSG) and optimal SEO metadata delivery.
* 🌊 **Staggered Micro-Interactions:** Fluid scroll-triggered viewport animations powered by Framer Motion, utilizing custom Bézier easing curves (`[0.22, 1, 0.36, 1]`) for natural kinetic feel.
* 📱 **Flawlessly Responsive:** Engineered mobile-first with adaptive multi-column layouts and an animated mobile navigation drawer.
* 💠 **Custom SVG Iconography:** Inline SVG brand integrations alongside `lucide-react` icons ensuring zero dependency collisions and crisp scaling at any resolution.

## 🚀 Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites

Ensure you have Node.js (v20+) installed:
```bash
node -v
```

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sainath-16/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in Browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application live.
